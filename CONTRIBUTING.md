# Contributing to PentaHydra Agency Systems

Thank you for considering contributing to PentaHydra Agency Systems engineering and AI repositories.

## How Can You Contribute?

### Areas

* AI Engineering & Agentic Systems
* Data Engineering & Analytics
* GIS / GeoAI
* IoT & Edge Computing
* Industrial Automation
* Engineering Automation

### Development

* Fork the repository
* Create a feature branch: `git checkout -b feature/amazing-feature`
* Commit your changes: `git commit -m 'Add: amazing feature'`
* Push to the branch: `git push origin feature/amazing-feature`
* Open a Pull Request

## Development Guidelines

* All engineering and AI systems must adhere to the Core Engineering architecture outlined in the profile README
* No API keys, passwords, tokens, or private credentials should be committed
* Documentation must be updated for any new component or integration
* Code reviews are required for all contributions and must pass validation engine checks

## Pull Request Process

1. Ensure your contribution aligns with the modular architecture (Agent Runtime, Tool Registry, Orchestrator, Planner, Execution Engine, Validation Engine, RAG, Knowledge Graph, Provenance, Audit Trail, Workspace, AI Provider Layer)
2. Pass all applicable architecture and validation reviews
3. Update documentation to reflect changes in the engineering operating environment
4. Maintain provenance and audit trail requirements for all modifications

## Code of Conduct Participation

By participating in this project, you agree to abide by the Code of Conduct in the `.github/CODE_OF_CONDUCT.md` file.
